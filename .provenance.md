# Source Provenance

This file records the documentary provenance of the sequences implemented
in this crate. It is intentionally excluded from the public-facing README:
the library presents itself as a pure mathematics library, and the
historical mapping lives here only.

## Default source

Every series and sum in this crate is a closed-form rendering of the
toe-ta-sul (퇴타술, piled-series methods) recorded in Yi Sang-hyeok's
*Iksan* (익산, 1855), second volume (하편 퇴타술): the simplex-number
families, iterated square sums, index-weighted (남봉) sums, truncated pile
sums (절적), cone-pile sums (원추타적), cube sums, and the cheonwon-sul
(천원술) application problems [30]-[41].

Further correspondence: `roots::positive_integer_root` is the modern
rendering of the equation-solving step (개방법) of those application
problems.

## Classical-name correspondence

The rows of the source text's seven-position law table (각적 칠위 법실표)
map onto these functions:

| Classical name | Definition | Function | Closed form |
|---|---|---|---|
| 교초적 (茭草積) | `sum k` | `simplex_number(n, 1)` | `C(n+1, 2)` |
| 삼각타적 (三角垛積) | `sum S_k^1` | `simplex_number(n, 2)` | `C(n+2, 3)` |
| 삼각낙일적 (三角落一積) | `sum S_k^2` | `simplex_number(n, 3)` | `C(n+3, 4)` |
| 삼각살성적 (三角撒星積) | `sum S_k^3` | `simplex_number(n, 4)` | `C(n+4, 5)` |
| 사각타적 (四角垛積) | `sum k^2` | `iterated_square_sum(n, 1)` | `n(n+1)(2n+1)/6` |
| 사각낙일적 (四角落一積) | `sum T_k^1` | `iterated_square_sum(n, 2)` | `n(n+1)^2(n+2)/12` |
| 사각살성적 (四角撒星積) | `sum T_k^2` | `iterated_square_sum(n, 3)` | `n(n+1)(n+2)(n+3)(2n+3)/120` |
| 교초남봉적 (茭草嵐峰積) | `sum k * S_k^1` | `generalized_series_sum(n, 2)` | `n(n+1)(n+2)(3n+1)/24` |
| 삼각남봉적 (三角嵐峰積) | `sum k * S_k^2` | `generalized_series_sum(n, 3)` | `n(n+1)(n+2)(n+3)(4n+1)/120` |
| 사각남봉적 (四角嵐峰積) | `sum k * T_k^1` | `weighted_partial_square_sum(n)` | `n(n+1)(n+2)(8n^2+11n+1)/120` |
| 정방남봉적 (正方嵐峰積) | `sum k^3` | `power_sum(n, 3)` | `(n(n+1)/2)^2` |
| 정방남봉갱낙일적 | double sum of cubes | `iterated_power_sum(n, 3, 2)` | `n(n+1)(n+2)(3n^2+6n+1)/60` |
| 원추타적 (圓錐垛積) | cone-pile layer sum | `interleaved_series_sum(n)` | `((2n+1) * S_n^1 + ceil(n/2)) / 4` |
| 절적 (截積) | `sum k * sum (m + j - 1)^2` | `weighted_shifted_square_sum(m, n)` | simplex-basis finite-difference expansion |
| 절적 일반화 | `sum k * T_{m+k-1}^1` | `weighted_shifted_pyramidal_sum(m, n)` | simplex-basis finite-difference expansion |

## Exceptions (not recorded in *Iksan*)

The following three elementary centered polygonal expansions are **not**
recorded in *Iksan*; they predate it as basic figurate-number material and
are included as building blocks. All are special cases of
`series::centered_expansion`.

| Function | Classical name | Sequence |
|---|---|---|
| `series::centered_triangular_number` | 삼릉전적 (三陵展積) | `1, 4, 10, 19, 31, ...` |
| `series::centered_hexagonal_number` | 원전적 (圓展積) | `1, 7, 19, 37, ...` |
| `series::odd_square` | 방전적 (方展積) | `1, 9, 25, 49, ...` — layers add `8k` dots, twice the standard centered-square count |

## Errata found in the reference summary

Transcription errors found while cross-checking the reference summary
against direct computation; all are encoded and documented in
`tests/reference.rs`:

- Problem 1 ([30]): the stated total `15980` is inconsistent with the
  summary's own equation; the consistent value is `15990`.
- Problem 7 ([36]): the displayed convolution `sum p_k w_k (n - k + 1)`
  does not match the summary's own quartic; the consistent model is the
  cumulative crew times the day-of-work wage.
- Problems 9/10 ([38], [39]): the summary's polynomials are already in the
  unshifted day-count variable (root `N = 15`), despite the "n + offset"
  commentary.
- Problem 12 ([41]): the sextic resultants carry transcription errors
  (swapped `n^5`/`n^4` coefficients and a flipped `n^3` sign; a flipped
  `m^5` sign). The true Sylvester resultants, recomputed independently,
  are used instead.
- Sagak-salseong row of the law table: the expanded polynomial
  `n(n+1)(n+2)^2(n+3)/20` is inconsistent with its own basis expression;
  the correct expansion is `n(n+1)(n+2)(n+3)(2n+3)/120`.
